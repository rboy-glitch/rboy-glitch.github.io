Spam Purger

Spam Purger is a personal tool that automatically and permanently deletes messages in the owner's Gmail Spam folder as soon as they arrive.

It is used only by its owner on the owner's own Gmail account. It is not offered to the public, and it has no user accounts or sign-up.

How it works

  • Gmail sends a notification when the Spam folder changes.
  • A small program on Google Cloud lists the messages in Spam and permanently deletes them.
  • The program reads only message IDs. It doesn't read, store or share message contents.
